# JJJCB-Medwell
The idea behind the P3 project for Medwell Solutions is to create a functioning prototype that can verify participation, award points, manage campaign content, and provide measurable reporting to partners.
Essentially, P3 encourages people to participate in and complete approved events, activities, and learning materials, then allows those running these initiatives to verify, track, and report on engagement.
